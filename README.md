# Portfolio_Soyamo_Vakala

My personal portfolio website, showcasing my work as a Computer Science Honours graduate with interests in software engineering, data systems, and AI security.

Explore projects spanning deepfake detection, fraud monitoring, algorithmic trading, e-commerce, and ticket management. Each project outlines the problem, my contribution, and the technical decisions behind the solution.

The website also introduces my technical skills, education, and approach to building software, with links to my résumé, GitHub, LinkedIn, and email.

Built with **React**, **Three.js**, and **Vite**, featuring an interactive 3D animation, responsive layouts, and light and dark themes.
